## Portfolio Sections

### 1. Linux Commands & System Documentation (CO1)
Documents my workstation's hardware and OS details, plus a manual binary conversion walkthrough.
- [`Linux/system_profile.md`](Linux/system_profile.md): system specs table and binary number representation
- [`Linux/commands_output.txt`](Linux/commands_output.txt): output of `ls -la`, `ps aux`, `df -h`, `free -h`

### 2. Shell Scripting & Automation (CO2)
Two Bash scripts that automate practical developer tasks.
- [`ShellScripts/sysinfo.sh`](ShellScripts/sysinfo.sh): prints a formatted system information report
- [`ShellScripts/backup.sh`](ShellScripts/backup.sh): creates a timestamped `.tar.gz` backup and logs the result
- [`ShellScripts/sysinfo_output.txt`](ShellScripts/sysinfo_output.txt): saved output of `sysinfo.sh`

**Usage:**
```bash
chmod +x ShellScripts/*.sh
./ShellScripts/sysinfo.sh
./ShellScripts/backup.sh ~/DeveloperPortfolio
```

### 3. GitHub & API Interaction (CO3)
Fetching and analysing real data from REST APIs using `curl` and `jq`.
- [`API/github_profile.json`](API/github_profile.json): my GitHub profile data
- [`API/sample_posts.json`](API/sample_posts.json): sample data from JSONPlaceholder
- [`API/api_summary.md`](API/api_summary.md): REST API concepts, HTTP status codes, and `jq` filters

### 4. Developer Portfolio & Career Roadmap (CO4)
My professional presence and future learning plan.
- [`Portfolio/resume.pdf`](Portfolio/resume.pdf): one-page technical resume
- [`Portfolio/learning_roadmap.md`](Portfolio/learning_roadmap.md): semester-wise learning roadmap
